## **Descripción del proyecto**

Una empresa de desarrollo de software desea construir una versión académica del juego Sokoban como producto base para futuras extensiones (editor de niveles, analizador automático de soluciones, ranking global, etc.).

El sistema consiste en una aplicación de escritorio con interfaz gráfica 2D desarrollada en JavaFX, que permite a los usuarios jugar niveles cargados desde archivos externos en formato JSON.

El objetivo principal del juego es ubicar todas las cajas en las posiciones objetivo dentro de un tablero representado como una cuadrícula bidimensional. El jugador puede moverse en cuatro direcciones y únicamente puede empujar cajas si la casilla siguiente está libre. No es posible jalar cajas.

El sistema valida movimientos, detecta condiciones de victoria y permite gestionar información relacionada con las partidas, como estadísticas, tiempos y movimientos realizados.

Además, el proyecto se desarrolla bajo principios de ingeniería de software, incluyendo el uso de arquitectura MVC, estructuras de datos, algoritmos de búsqueda y pruebas automatizadas.
